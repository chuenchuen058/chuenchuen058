I build things that move and the software/electronics that make them work. Biomedical Engineering student at King's College London, based in Penang, Malaysia, looking for roles in robotics and automation.

### Denisse

A personal AI assistant in the direction of Jarvis — a local Python daemon wrapping the Claude API with tool-use, so it can act on the machine (run commands, open apps, read/write files) rather than just answer questions. v1: text chat, system control, and persistent memory across restarts. Private for now.

### UnibotsMarkII

A 4-wheel ESP32-based robot — TB6612FNG motor drivers, MPU6050 IMU, N20 encoder motor. Currently in hardware bring-up and test: diagnosing wiring faults (a fried ESP32 from a back-fed 12V rail was one of them), writing per-wheel motor test sketches, getting the state machine and sensor fusion solid before it moves under its own control.

Repo: UnibotsMarkII

### Also built

Sobriety-controlled dispenser — a hackathon build on an Arduino UNO R3: state machine, OLED display, RFID, servo and stepper-driven carriage, versioned incrementally across six sketches.

CAD & competition work — Fusion 360 design for the Olympus Rover Trials.
